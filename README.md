# 🏥 Hospital Management System

A full-stack Hospital Management System built using React.js, Node.js, Express.js, and PostgreSQL to manage OP bookings, patient records, billing workflows, authentication, and admin operations.

---

# 🚀 Features

- OP Booking Management
- Patient Record Handling
- Billing & Invoice Generation
- Revenue Tracking Dashboard
- JWT Authentication
- Role-Based Access Control
- REST API Integration
- Modular MVC Backend Architecture
- PostgreSQL Database Integration
